# 💻 PHP CLI Tools

A personal collection of **PHP command-line tools** to make development faster and easier.  

---

## 🛠 Tools Included

- **Git Helper** – Automates git init, commit, branch, push.  
- **API Tester** – Test APIs from terminal with JSON response.  
- **Slim Helper** – Scaffold Slim projects & manage routes.  
- **Custom Script** – Miscellaneous personal scripts for daily tasks.  

> Built with pure PHP, no frameworks needed.

---

## ⚡ Requirements & Run

- PHP **8.0+**  
- Terminal access  

Check PHP version:

```bash
php -v
```
## Run a tool:
```
php tool-name
```

## Example:
```
php git
```

```
php slim
```

```
php curl
```
